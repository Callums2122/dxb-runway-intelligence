# DXB RUNWAY Team

Official release channel for the DXB RUNWAY Team desktop application.

This repository contains release packages and cryptographic update manifests only.
It does not contain DXB Runway source code, databases, customer records, stock data,
credentials or company integrations.

DXB RUNWAY Team checks this channel for updates and always asks the user before
installing. Every download is verified against its published SHA-256 checksum, and
the colleague's local database is preserved during application updates.

## Current platform

- macOS — Apple Silicon

Use the latest release assets to install the app manually. Existing Team users can
install later releases through the in-app update prompt.
